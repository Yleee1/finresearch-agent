# V4 结构化表格分块候选实验

## 实验边界

V4 仅替换 PDF 分块方式：正文继续语义分块，表格按完整行组分块，每个子块重复表头，
并保留 `table_id`、页码和行范围。V3 代码、语料和冻结结果未被覆盖。

V4 gold 语义沿用 V2 的 128 条检索样本和 74 条 Agent 样本，只迁移了证据块 ID。
`data/eval/v4_candidate/manifest.json` 记录了输入、输出和语料 SHA-256；
`migration_audit.jsonl` 保留 60 条新旧 ID、页码、块类型和证据摘要。这是配对开发对照，
在独立人工复核前不宣称为新的冻结基准。

## 可复现配置

- 语料：比亚迪与宁德时代 2024 年报。
- 问题：128 条 V2 评测样本，V3/V4 问题文本和证据语义相同。
- R0：BM25 Top-5。
- R1：BM25 召回 20 个候选，`BAAI/bge-reranker-base` Cross-Encoder 精排至 Top-5。
- R2：在 R1 上最多扩展 2 个前后邻块。
- 设备：CPU，模型从本地 Hugging Face 缓存离线加载。

## 结果

| 方案 | 版本 | Recall | MRR | NDCG | 证据槽覆盖 | 完整证据召回 |
|---|---|---:|---:|---:|---:|---:|
| R0 BM25 | V3 | 79.95% | 65.56% | 68.20% | 78.12% | 75.00% |
| R0 BM25 | V4 | 83.72% | 68.45% | 70.97% | 83.98% | 80.47% |
| R1 BM25 + Cross-Encoder | V3 | 86.46% | 72.15% | 74.04% | 85.55% | 82.81% |
| R1 BM25 + Cross-Encoder | V4 | 86.98% | 72.80% | 73.79% | 87.89% | 82.81% |
| R2 R1 + 邻块 | V3 | 89.97% | 72.50% | 75.39% | 89.84% | 88.28% |
| R2 R1 + 邻块 | V4 | 86.98% | 72.80% | 73.79% | 87.89% | 82.81% |

表格类 49 条样本上，R0 完整证据召回从 65.31% 提升到 83.67%（+18.36pp），
R1 从 77.55% 提升到 83.67%（+6.12pp）。这说明重复表头与按行组分块确实改善了
单表格问题的词法召回和精排识别。

R1 总体完整证据召回持平，但证据槽覆盖提升 2.34pp。原因是表格类收益被
跨表/跨公司 Top-5 的回归抵消。典型回归是 `fr031`（销售费用+管理费用分属两表）和
跨公司销售费用问题：V4 拆分后不再能依赖“同页混合块”一次命中两类证据。

R2 在 V4 上没有增益。V4 的邻块关系只连接同一逻辑表格内的行组，无法弥补两张独立表格
或两家公司的证据缺失。因此后续不应放宽邻块，而应对多证据槽进行查询拆解、
分槽召回后再合并去重和精排。

R1 单次 CPU 运行的平均查询时间从 1.580s 变为 1.913s。这是单次顺序测量，
只能作为开发信号，不作为 P95 或生产延迟结论。

## 结论

V4 结构化分块实现有效，但尚不替换 V3 冻结主线。在补上多证据槽独立召回、完成独立人工复核
并重新冻结前，它保持为 candidate 实验。
